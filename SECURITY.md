# Security Policy

## Supported versions

Security updates are maintained on the `main` branch.

| Version           | Supported |
| :---------------- | :-------- |
| `main` / `v1.0.x` | Yes       |
| Older commits     | No        |

## Reporting a vulnerability

If you find a security vulnerability, please report it privately:

1. **GitHub Security Advisory (preferred):** open the repository's **Security** tab, choose **Report a vulnerability**, and start a private advisory.
2. **Email:** send the details to [purvesh9997@gmail.com](mailto:purvesh9997@gmail.com) with `[SECURITY] BlogHub Vulnerability` in the subject.

Please allow up to 72 hours for an initial response before any public disclosure.

## How the app is protected

The protections already in place, and their known trade-offs, are described in [Security Model](docs/SECURITY_MODEL.md).
